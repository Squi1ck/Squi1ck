<h2 align="center">🚀 Sobre mim</h2>

**Dinis**, aqui — estudante de programação na escola profissional **Oficina** e treinador de patinagem no clube **CART**.

Gosto de programar e de jogar nos tempos livres, e de transformar ideias em projetos que funcionam, desde jogos simples até aplicações com base de dados.

De momento trabalho com **JavaScript, React, Node, C++ e C#**, e uso **MySQL e Supabase** para guardar dados. Também mexo em **Arduino** e tenho noções intermédias de arquitetura de computadores.

O meu objetivo é simples: escrever código limpo, criar bons jogos e software e crescer até me tornar programador profissional.
